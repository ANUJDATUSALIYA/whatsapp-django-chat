# ChatFlow

A Django-only WhatsApp-style chat web app with contact list, conversation view,
message bubbles, unread counts, search, and demo chat data.

## Run

```powershell
cd "C:\Users\anujj\OneDrive\Documents\GitHub\whatsapp-django-chat"
powershell -ExecutionPolicy Bypass -File .\run_app.ps1
```

Open:

```text
http://127.0.0.1:8020/
```

The project is prepared for deployment on AWS Elastic Beanstalk. Follow the steps in [AWS_DEPLOYMENT.md](AWS_DEPLOYMENT.md).
